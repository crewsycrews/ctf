## Run from VS Code

Install the recommended **Defold Kit** and **Local Lua Debugger** extensions.
Set `defoldKit.general.editorPath` to the actual Defold installation directory
(for Steam on macOS, use the app under `~/Library/Application Support/Steam/steamapps/common/Defold`, not the shortcut in `~/Applications`).

In **Run and Debug**, select **Build & Run** and press **F5**. This builds with
Defold Kit and launches with the Lua debugger. Use **Just Run** to launch the
last VS Code build without rebuilding. **Ctrl/Cmd+Shift+B** builds without launching.
Build output is in `build/defoldkit`; the Defold Editor's `build/default` output
is separate.
